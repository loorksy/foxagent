# FoxAgent — خطة التطوير الموحدة

| الحقل | القيمة |
| --- | --- |
| الحالة | معتمدة للنقاش — التنفيذ سفينةً سفينة |
| الواجهة الحية | `https://foxagent.lork.cloud` |
| المصدر | دمج قائمتي التطوير المتفق عليهما (غرفة العمليات + عقد الاستراتيجية) |
| التاريخ | سبتمبر 2026 |
| القاعدة اليوم | `main` بعد مختبر الاستراتيجيات؛ المسارات الحالية تحت `frontend/src/app/(desk)/` |

هذه الوثيقة هي مصدر الحقيقة لدورة البناء القادمة. أي تعارض مع الشات، هذه الخطة. أي تعارض مع الكود الحي، الكود هو الواقع ويُحدَّث هنا بعد كل سفينة.

> **إخلاء.** FoxAgent مكتب توصية لمشغّل واحد. لا ينفّذ أوامر، ولا يخترع شموعاً أو أخباراً. الصفقة قرار بشري.

---

## 0. الثوابت — غير قابلة للتفاوض

1. **XAU_USD فقط.** لا أزواج جديدة، لا تعدد وسطاء.
2. **البوابة في الكود** (`enforce_risk_gate`). لا برومبت يتجاوزها، ولا مسار ترقية موازٍ.
3. **Pause فوق الجميع.** يوقف الطاقم، مضخة الأسعار، مزامنة المستودع، وكل البوتات. Pause اليدوي يغلب أي قاطع تلقائي.
4. **لا بوت يضع أوامر وساطة.** الإشارة → اعتماد بشري → توصية عبر البوابة. لا `/trading` ولا `/portfolio` ولا تنفيذ OANDA.
5. **لا كود حر من الوكيل.** لا بايثون/JS يُنفَّذ، لا `eval`. العقد DSL حتمي يفهمه الماسح والباك تست معاً.
6. **لا اختلاق أخبار.** فشل الكشط = قائمة فارغة. كل حدث صف حقيقي من المصدر أو لا يظهر.
7. **لا تفعيل صامت.** التثبيت بشري بعد العتبات. `auto_activate=True` في `validate_strategy` يُلغى في السفينة 2.
8. **RTL عربي أولاً** على كل شاشة جديدة؛ مفاتيح `ar.ts` / `en.ts` معاً. `MessageKey` من العربية.
9. **كل سفينة تُغلق باختبار ثم نشر** على `foxagent.lork.cloud` قبل التالية.

## 1. أين نحن اليوم (من الكود، لا من الأمنية)

المكتب يعمل كمحطة مشغّل واحد: شات طاقم + شارت + توصيات + ذاكرة + تقويم + بوت ذهب + باك تست + مختبر.

| الموجود | الواقع |
| --- | --- |
| المسارات | `/` `/agents` `/agents/:id` `/recommendations` `/memory` `/calendar` `/bot` `/backtest` `/strategy-lab` `/settings` |
| البوت | منسّق واحد في `TradingBotCoordinator` فيه ثلاثة وكلاء داخليون: هيكل (`MultiStrategyAgent`) · أنماط (`PatternNotesAgent`) · شمعة خبر (`NewsCandleAgent`). صفحة واحدة `/bot` |
| الاستراتيجيات | عقد `StrategyRule` بأعلام (`asian_sweep`, `fvg_exists`…) عبر `StrategyForm`. الخمس المدمجة (`BUILTIN_IDS`) غير قابلة للحذف ودائماً `active` |
| التحقق | `POST /api/strategies/:id/validate` + أداة MCP `validate_strategy` تستدعي `auto_activate=True` فتصير الاستراتيجية حيّة بلا تثبيت بشري |
| الحالات | `draft / validated / active / rejected / archived` — لا `pinned` ولا `experimenting` |
| الجلسات | إعدادات `london / ny / asian`؛ كثير من القواعد مربوطة بنطاق آسيا كقيد لا كمستوى سيولة |
| الإشارات | `GET/PATCH /api/bot/signals` و`POST .../to-recommendation` (ثقة > 0.8). لا طابور stage/commit، لا رفض بسبب محفوظ ككيان وارد |
| المسح | عدّاد `cycles` في المنسّق. لا دفتر دورة، لا `scanId`، لا خط زمني |
| الباك تست | محرّك حتمي على المستودع. `GET /api/backtest/reports` موجود. الواجهة تشغّل تقريراً جديداً فقط — لا قائمة محفوظة ظاهرة، رغم أن النوع فيه `bySession` / `byMonth` |
| التقويم | Forex Factory + `WATCHLIST` قصيرة (NFP, CPI, FOMC, GDP, payroll, PMI/ISM, PPI, PCE, Powell…). وكيل الخبر موجود ككود لا كمكتب |
| تيليجرام | تنبيه توصية + لقطة شارت. لا إحاطة مجدولة، لا أوامر واردة، لا تنبيه stale/خبر |
| الحوكمة | Pause عام. لا قاطع لكل استراتيجية، لا safe mode، لا سقف إشارة/ساعة |
| الشات | طاقم ثابت + حلقة أدوات. عداد توكن إن دُمج من فرعه. بطاقة مقترح استراتيجية موجودة؛ لا حلقة تجربة ≤8 ولا `/strategy-lab/jobs/:id` |
| المستودع | M15 / H1 / H4 / D — نافذة سنتين. لا M1 حول الخبر بعد |

**ما لن نعيد بناءه:** الشارت (klinecharts + overlays)، الطاقم، البوابة، Pause، المستودع، محرّك الباك تست، مسار الترقية الحالي. الجديد يستدعيها.

## 2. صورة الهدف عند إغلاق الخطة

مشغّل واحد، ذهب فقط:

- صباح المكتب: شريط علوي (وضع · Pause · البوتات · الوارد · المستودع · الخبر القادم) + `/inbox` فيه ما يحتاج قراراً.
- إشارة البوت **staged** حتى تعتمدوا أو ترفضوا بسبب. الاعتماد يمر بالبوابة ويصير توصية.
- عدة بوتات لكل منها مسار (`/bots/structure` `/bots/patterns` `/bots/news` `/bots/:id`). Pause يوقف الجميع.
- الاستراتيجية عقد DSL (جلسة + محفّز + شروط + دخول/وقف/R) لا صناديق اختيار فقط. الخمس قوالب قابلة لفك التثبيت، لا تُحذف من المحرك.
- من الشات: «اصنع استراتيجية كذا» → مسودة → حتى 8 باك تستات مستودع → بطاقة حيّة → تثبيت بشري. لا هلوسة شموع.
- تيليجرام: إحاطة قبل لندن + تنبيهات تشغيلية + أوامر `/status` `/pause` `/inbox`. الاعتماد يبقى بشرياً على الويب أولاً.
- كل أثر يفتح مصدره: توصية → جلسة، إشارة → `scanId`، تقرير → استراتيجية.

## 3. عقد الاستراتيجية — قواعد قابلة للتشغيل، لا بايثون حر

الوكيل **لا** يكتب كوداً يُنفَّذ. ذلك يتجاوز البوابة وPause ويفتح حقن كود.

### 3.1 شكل العقد (DSL)

حتمي، يفهمه الماسح والباك تست، يُعرض كمحرر كتل أو JSON واضح:

| الحقل | القيم |
| --- | --- |
| جلسة | آسيا · لندن · نيويورك · تداخل لندن–نيويورك · إغلاق لندن |
| محفّز | كنس سيولة · كسر نطاق · FVG · انزياح هيكل · رفض عند OB · شمعة خبر |
| شروط | اتجاه الإطار الأعلى · خصم/علاوة · قبل خبر / بعده (من التقويم الحقيقي) |
| إدارة | دخول · وقف · أهداف R · أقصى احتفاظ |
| اتجاه | شراء · بيع · الاثنان |
| رمز | `XAU_USD` فقط — ثابت في المحرك لا في البرومبت |

نطاق آسيا **مستوى سيولة** يُستخدم في لندن/نيويورك، لا قيد يلغي باقي اليوم. بوت «كل الجلسات» يمسح الأربع؛ بوت سكالب قد يُثبَّت على التداخل فقط.

لندن في الإحاطة = **ساعة تيليجرام قبل الفتح**، ليست جلسة التداول الوحيدة.

### 3.2 حالات القاعدة

| الحالة | المعنى | تُمسح حيّاً؟ |
| --- | --- | --- |
| مسودة `draft` | وُصفت أو ولّدها الوكيل | لا |
| قيد التجربة `experimenting` | الوكيل يكرّر الباك تست | لا |
| تجاوزت العتبات `validated` | تنتظر التثبيت | لا |
| مثبتة `pinned` (اليوم: `active`) | تدخل مسح البوت المعني | نعم |
| مفكوكة `unpinned` | في المكتبة | لا |
| مرفوضة / مؤرشفة | سبب محفوظ | لا |

التثبيت يدوي بعد نجاح العتبات (أو بعد جولة الوكيل + موافقتكم). الخمس الحالية تتحول إلى **قوالب مثبتة** يمكن فك تثبيتها (تُؤرشف من المسح). لا تُحذف من المحرك حتى يبقى المكتب قابلاً للعمل إن فُرغت المكتبة.

### 3.3 حلقة الوكيل — وصف → تجربة ≤8 → تثبيت بشري

1. تكتبون في الشات: «كنس آسيا ثم دخول FVG في لندن، RR≥2، لا خبر high قبل 30 د».
2. الوكيل يترجم إلى عقد DSL (ذهب فقط) عبر أداة، لا عبر توليد سكربت.
3. يحفظ **مسودة** ويشغّل باك تست المستودع (حتمي، بلا شبكة).
4. إن فشلت العتبات: يعدّل شرطاً واحداً (جلسة، وقف، إطار…) ويعيد التجربة.
5. سقف **8 محاولات** أو حتى توقفوا. بلا سقف = حرق رصيد وملاءَمة منحنى.
6. النجاح = عتبات المختبر (`WR ≥ 0.55` · `PF ≥ 1.5` · صفقات ≥ 50 · DD ≤ 15R · إجمالي R ≥ 10) + عينة خارج العينة إن وُجدت. ليس «أعجب الوكيل».
7. إن نجحت: تبقى **بانتظار اعتمادكم**. إن استنفدت: أفضل نسخة + أسباب الفشل.

تبقون في `/agents/:id`. بطاقة حيّة في المحادثة، وصفحة `/strategy-lab/jobs/:id` للخط الزمني. بعد التثبيت: زر «أضف لبوت الهيكل / أنشئ بوتاً». لا صفقة من هذا المسار.

العتبات الحالية في `VALIDATION_THRESHOLDS` تبقى المرجع حتى تُغيَّر بقرار صريح في الإعدادات.

## 4. البوتات — غرفة لا كومة واحدة

بدل `/bot` كصفحة وحيدة:

| المسار | البوت | ماذا يمسح |
| --- | --- | --- |
| `/bots` | الغرفة | تشغيل/إيقاف، قاطع، آخر دورة لكل بوت |
| `/bots/structure` | الهيكل | القواعد المثبتة (ICT/SMC) |
| `/bots/patterns` | الأنماط | العشر شموع |
| `/bots/news` | شمعة الخبر | التقويم + نافذة الحدث (الوكيل الحالي بعد رفعه) |
| `/bots/:id` | بوت تنشؤونه | حزمة قواعد + جلسات + عتبة ثقة |

كل بوت: on/off مستقل، جلساته، سقفه، قاطعه، دفتر مسح. **Pause العام يوقف الجميع.** الترقية للتوصية تمر بنفس البوابة.

`/bot` تبقى تحويلاً إلى `/bots` حتى لا تنكسر الإشارات المرجعية.

### بوت شمعة الخبر (نصف موجود)

`NewsCandleAgent` يقرأ أحداث high خلال 6 ساعات:

| النافذة | اللعب |
| --- | --- |
| قبل 1–12 د | `pre_news_gold` |
| 0–3 د | زخم |
| 5–10 د | ارتداد |
| 10–20 د | عكس |

يُرفع إلى مكتب `/bots/news`: قبل الحدث حالة «نافذة خبر» بلا هيكل عام؛ بعد النافذة صمت أو تسليم للوارد. تيليجرام: «خبر خلال 30 د» ثم إشارة الشمعة إن وُجدت. باك تست خبر على M1 لاحقاً — المستودع اليوم M15+.

### قائمة أخبار الذهب — أوسع، بلا اختلاق

المصدر الحالي Forex Factory. نوسّع **قائمة الرصد** فقط. كل حدث يبقى صفاً حقيقياً أو لا يظهر.

ما يستحق الرصد (USD + ماكرو + تقاطع إن ورد من المصدر):

- عمل وفيد: NFP، بطالة، مطالبات، متوسط الأجر، FOMC، المعدّل، خطاب باول، محضر، dot plot
- تضخم: CPI / Core، PCE / Core، PPI
- نمو: GDP، تجزئة، ISM/PMI تصنيع وخدمات
- دولار وعائد: DXY إن وُجد كحدث/تغذية، مزادات سندات عند الحاجة
- الصين (طلب الذهب الفعلي): PMI / ائتمان / ناتج **إن وُجدت من المصدر**
- ملاذ: مفاجآت جيوسياسية **فقط إن وردت من التقويم/التغذية**
- معادن: مخزون/طلب رسمي من المصدر نفسه إن وُجد

فشل الكشط = قائمة فارغة. لا NFP وهمي. التأثير `low/medium/high/critical` يصفّر بوت الخبر. مصدر ثانٍ لاحقاً للدمج لا للهلوسة.

## 6. تجربة المستخدم (ما يلمسه المشغّل يومياً)

1. **شريط علوي:** وضع المكتب · Pause · البوتات · عدد الوارد · المستودع (طازج/stale) · الخبر القادم.
2. **لوحة أوامر (Ctrl+K):** صفحات، `/scan` `/setup`، إشارات معلّقة، تقارير باك تست.
3. **Preflight مرئي** عند تشغيل أي بوت: قائمة فحص بخاخات نجاح/فشل.
4. **خط زمني حي** على مكتب البوت: أحداث الدورة لحظة حدوثها.
5. **بطاقات اعتماد** لا صفوف جدول فقط: دخول/وقف/R/ثقة/سبب + أزرار إبهام.
6. **من أي أثر → مصدره.**
7. **RTL عربي أولاً** + مفاتيح i18n متزامنة.
8. **جوال:** الوارد والاعتماد قائمة لا جدول عريض فقط.
9. **حالات فارغة صريحة:** لا إشارة، المستودع فارغ، البوت متوقف، Pause — لا شاشة سوداء / لا React #185 من `|| []` في Zustand.
10. **أول تشغيل موجّه (اختياري، آخر الخطة):** مفاتيح → المستودع → الاستراتيجيات → شرح Pause.

الشارت الحالي يكفي. لا TradingView في هذه الخطة.

## 7. سفن التنفيذ

ترتيب واحد. كل سفينة: اختبار → التزام → نشر حي → التالية. لا نفتح سفينتين على الإنتاج معاً.

الاعتمادية: الوارد يعمل على الإشارات الحالية بلا DSL. حلقة الوكيل والبوتات المتعددة تحتاج حالة تثبيت ثم عقد DSL. بوت الخبر يُرفع من الوكيل الحالي دون انتظار DSL كامل.

```text
1 وارد/اعتماد/Preflight
        │
        ▼
2 تثبيت بشري + إلغاء auto_activate + حقل الجلسات
        │
        ▼
3 /bots + /bots/news + /bots/structure
        │
        ▼
4 DSL بدل الأعلام + القوالب الخمسة قابلة لفك التثبيت
        │
        ▼
5 حلقة الوكيل ≤8 + بطاقة شات + /strategy-lab/jobs/:id
        │
        ▼
6 سجل مسح + خط زمني + قاطع مسمّى
        │
        ▼
7 إحاطة تيليجرام + stale/خبر
        │
        ▼
8 تاريخ باك تست + لوحة ترتيب + bySession/byMonth
        │
        ▼
9 أوامر تيليجرام + تشريح + مهام قبل لندن
        │
        ▼
10 صلابة (ترحيل جداول، حد معدّل، نسخة احتياطية)
```

### سفينة 1 — غرفة العمليات

**لماذا أولاً:** قيمة يومية فورية على الإشارات الموجودة، بلا انتظار عقد جديد.

**يُبنى**

- `/inbox` بتبويبات وارد · اعتماد · تنبيهات.
- تجميع: إشارات بلا قرار، توصيات بلا وسم، مستودع stale، خبر high خلال 30 د، آخر خطأ مسح.
- طابور اعتماد: إشارة `staged` → اعتماد يمر بـ `signal_to_recommendation` + `enforce_risk_gate`، أو رفض **بسبب محفوظ** (الصف لا يُمسح).
- `GET /api/bot/preflight` + قائمة مرئية قبل `POST /api/bot/start`.
- شارة العدد في الشريط الجانبي.
- بطاقة حالة مكتب خفيفة في أول `/setup` (من الكود: Pause، بوت، مستودع، خبر قادم).

**اختبارات:** vitest لقائمة وارد فارغة + بطاقة اعتماد؛ pytest لمسار اعتماد/رفض لا يتجاوز البوابة.

**تعريف الإنجاز:** على الحي، إشارة معلّقة تظهر في `/inbox` وتُعتمد أو تُرفض بسبب دون اختفاء الصف.

### سفينة 2 — لا تفعيل صامت

**يُبنى**

- إلغاء `auto_activate=True` من `tool_validate_strategy` ومسار API إن مُرِّر من العميل.
- الحالات: `validated` = نجحت العتبات وبانتظار التثبيت؛ التثبيت فقط `approve` البشري.
- حقل `sessions[]` على كل قاعدة (آسيا/لندن/نيويورك/تداخل/إغلاق لندن) دون كسر الأعلام الحالية.
- الخمس المدمجة تُعلَّم `pinned=true` وقابلة لفك التثبيت (تخرج من المسح، تبقى في المحرك).
- منع الحذف الجسدي للقوالب.

**اختبارات:** pytest يثبت أن `validate` لا يصيّر `active`؛ فك تثبيت قالب يخرجه من مسح الهيكل.

**تعريف الإنجاز:** اقتراح من الشات يبقى مسودة/validated حتى تضغطوا تثبيتاً.

### سفينة 3 — غرفة البوتات + مكتب الخبر

**يُبنى**

- `/bots` غرفة: بطاقة لكل وكيل (هيكل، أنماط، خبر) on/off مستقل.
- `/bots/structure` و`/bots/news` (الأنماط ثالثاً إن ضاق الوقت داخل السفينة).
- `/bot` → `/bots`.
- بوت الخبر: نافذة حدث، صمت خارجها، تسليم إشارة للوارد.
- توسيع `WATCHLIST` فقط من عناوين حقيقية. لا أحداث اصطناعية في الاختبار إلا كـ fixtures معلَّمة.
- Pause ما زال يوقف الثلاثة.

**اختبارات:** pytest لـ `NewsCandleAgent` كما هو + حالة نافذة؛ vitest لغرفة `/bots` فارغة/متوقفة.

**تعريف الإنجاز:** `/bots/news` يظهر نافذة خبر حقيقية أو حالة فارغة صريحة. لا عنوان مخترع.

### سفينة 4 — DSL

**يُبنى**

- مخطط عقد واحد يقرأه `MultiStrategyAgent` و`BacktestEngine`.
- محرر كتل في المختبر (الـ JSON تحت التفاصيل). الأعلام القديمة تُترجم مرة واحدة إلى العقد.
- لا محسّن معاملات آلي.
- باك تست من الشات يستدعي المحرك الحالي فقط.

**اختبارات:** pytest: نفس القاعدة كأعلام ثم كـ DSL تعطي نفس قرارات المحرك على شموع ثابتة.

**تعريف الإنجاز:** استراتيجية جديدة تُحفظ وتُمسح كعقد؛ القوالب الخمس ما زالت تعمل بعد الترجمة.

### سفينة 5 — حلقة التجربة من الشات

**يُبنى**

- أداة `experiment_strategy` (أو توسيع propose/validate): سقف 8، تعديل شرط واحد في كل جولة، Pause يلغي الوظيفة.
- بطاقة حيّة في المحادثة: الاسم، الجلسات، محاولة n/8، WR/PF/DD، نجح/فشل.
- `/strategy-lab/jobs/:id` خط زمني لكل نسخة + التقرير.
- تبويب «تجارب» في `/strategy-lab`.
- بعد النجاح: زرا ثبّت / ارفض. بعد التثبيت: أضف لبوت الهيكل أو أنشئ بوتاً.

**اختبارات:** pytest لسقف 8 وعدم التثبيت التلقائي؛ vitest لبطاقة المحاولة.

**تعريف الإنجاز:** وصف واحد في الشات ينتج مسودة + محاولات مرئية + انتظار تثبيتكم. لا شموع مخترعة.

### سفينة 6 — المسح والحوكمة

**يُبنى**

- دفتر قرار لكل دورة (`scanId`) حتى بلا إشارة. `/scans` و`/scans/:id`.
- بث SSE/WS لأحداث المسح والقاطع (`/ws/bot` أو `/api/bot/stream`).
- خط زمني حي على مكتب البوت بدل استطلاع 15ث.
- قاطع لكل استراتيجية: سلسلة خسائر / تراجع R / تهدئة. شارة `CircuitBadge`.
- Safe mode بعد N إخفاقات مسح أو تقويم — حظر إشارات جديدة حتى إقرار في الوارد.
- سقف إشارة/ساعة + تهدئة بعد خسارة + منع تكرار نفس الفكرة.
- اعتراض إلزامي قبل الترقية: جلسة غير مسموحة، خبر high، FVG مُفرَغ.
- إيقاف استراتيجية واحدة دون إيقاف البوت (`POST /api/bot/strategies/:id/halt`).
- Pause اليدوي يغلب القواطع.

**اختبارات:** pytest للقاطع والـ safe mode وPause؛ vitest لحالات الخط الزمني الفارغة.

### سفينة 7 — تيليجرام التشغيلي

**يُبنى**

- إحاطة مجدولة قبل لندن: سعر، مستودع، Pause/بوت، معلّق، بلا وسم، أخبار 24س. نفس المحتوى على `/briefing`.
- تنبيه `stale` / 429 متكرر / فشل مسح.
- تنبيه خبر high خلال 30 د.
- تنبيه قاطع.
- تنبيه إشارة للنقاش + رابط `/inbox` (الاعتماد على الويب).
- حد إرسال لكل نوع. كل رسالة فيها رابط المسار.
- الإبقاء على تنبيه التوصية + اللقطة كما هو.

**اختبارات:** pytest لتنسيق الإحاطة مع تقويم فارغ/stale؛ لا إرسال مزدوج لنفس الحدث.

### سفينة 8 — الباك تست والمختبر

**يُبنى**

- قائمة التقارير المحفوظة على `/backtest` (الـ API جاهز).
- جداول `bySession` و`byMonth` في الواجهة (الحقول موجودة في النوع).
- `GET /api/lab/leaderboard` + لوحة ترتيب: WR / PF / DD / الصفقات / تاريخ التحقق.
- تحقق خارج العينة (سنة/سنة) قبل `approve`.
- شارة الحالة: نشطة · مسودة · رُفضت · أوقفها القاطع.
- لا محسّن معاملات.

**اختبارات:** vitest لتقرير فارغ (لا تكرار لعطل React #185) + قائمة تاريخ فارغة.

### سفينة 9 — أوامر تيليجرام + ذاكرة القرار

**يُبنى**

- أوامر من الشات المسموح فقط: `/status` `/pause` `/resume` `/inbox`.
- لاحقاً داخل السفينة إن استقرّت البوابة: اعتماد/رفض برقم الإشارة (نفس مسار الويب).
- أطروحة + إبطال مكتوبان على كل توصية/إشارة معتمدة.
- تشريح إلزامي عند won/lost (`PATCH /api/recommendations/:id/postmortem`).
- تحديث فعالية القاعدة من التشريح.
- مهام مجدولة: قبل لندن · قبل NFP/FOMC · مراجعة مختبر أسبوعية → تكتب في الوارد.
- ربط: استراتيجية ↔ مسح ↔ إشارة ↔ توصية ↔ حدث ↔ درس.
- `/journal`.

**اختبارات:** pytest للأوامر المسموحة تُرفض من chat_id غريب؛ vitest لنموذج التشريح.

### سفينة 10 — الصلابة

**يُبنى**

- تنبيه تشغيلي عند stale طويل (إن لم يُغلق في 7).
- حد معدّل على `/api` وSSE.
- مسار ترقية جداول واضح (Alembic أو ما يعادله) **قبل** جداول الوارد/المسح إن لم تُرحَّل في السفن السابقة — إن فُتحت جداول في سفينة 1، هذه السفينة تغلق الثغرات لا تبدأ الترحيل من صفر.
- نسخة احتياطية مجدولة لـ DB + مفتاح التشفير.
- حزمة اختبارات الانحدار: وارد/اعتماد/باك تست فارغ · قاطع · بوابة · تيليجرام.
- أول تشغيل موجّه اختياري.

**تعريف الإنجاز:** نشر بلا `create_all` صامت على أعمدة جديدة؛ نسخة احتياطية قابلة للاستعادة في دليل التشغيل.
